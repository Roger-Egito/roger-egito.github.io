# Roger Egito's Game Dev Portfolio  

[My Website](https://roger-egito.github.io)

Built with [Astro](https://astro.build). No UI framework, no CSS framework, no runtime
dependencies. Design based on the
[Freelancer bootstrap theme](http://startbootstrap.com/template-overviews/freelancer/).

## Running it locally

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # type-checks, then writes dist/
npm run preview    # serve the built site
npm run check      # type-check on its own
```

## Where things live

| To change | Edit |
| --- | --- |
| Colors, type, spacing | `src/styles/tokens.css` |
| Name, slogan, social links, CV link | `src/config/site.ts` |
| A game's details | `src/content/games/<slug>.md` |
| About text | `src/components/About.astro` |
| Shared CSS (reset, buttons, layout) | `src/styles/global.css` |

Everything else is styled inside the component it belongs to, in that file's `<style>`
block. Astro scopes those automatically, so a rule in `Header.astro` can't leak out and
affect the footer.

Anything in `dist/` is generated by the build. Never edit it.

### Adding a game

1. Drop `<slug>.md` and `<slug>.webp` into `src/content/games/`.
2. Point `img:` at the image and give it an `order` higher than the others so it shows
   up first.

That one file produces the grid card, the popup and the standalone page. The build fails
if the image path is wrong, so a typo can't reach the live site.

Save source images as WebP around 1920px wide. Astro generates the smaller responsive
versions itself, so there's no need to resize anything by hand.

### How the popups work

Clicking a game opens a native `<dialog>` over the homepage and changes the URL to
`/games/<slug>/`. Back closes it. The same URL is also a real page, so shared links,
opening in a new tab and search engines all get proper HTML.

`<dialog>` handles focus trapping, Esc and the backdrop on its own, so
`src/scripts/modal.ts` only deals with the history and with loading the trailer lazily —
the YouTube player is only fetched once a game is actually opened.

## Notes

- Fonts are downloaded at build time and served from this domain, so there's no request
  to Google when someone loads the page.
- Icons are inline SVG (`src/components/Icon.astro`) rather than an icon font.
- The contact form uses the browser's own validation and CSS-only floating labels, so
  that section ships no JavaScript at all.

## Deployment

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds the site and
publishes it. This requires **Settings → Pages → Source = "GitHub Actions"**.
