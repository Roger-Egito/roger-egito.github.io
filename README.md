# Roger Egito's Game Dev Portfolio  

[My Website](https://roger-egito.github.io)

Built with [Astro](https://astro.build). Design based on the
[Freelancer bootstrap theme](http://startbootstrap.com/template-overviews/freelancer/).

## Running it locally

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # writes dist/
npm run preview    # serve the built site
```

## Where things live

| To change | Edit |
| --- | --- |
| Colours | `src/styles/tokens.css` (all of them, in one place) |
| Name, slogan, social links, CV link | `src/config/site.ts` |
| A game's details | `src/content/games/<slug>.md` |
| About text | `src/components/About.astro` |
| Theme CSS | `src/styles/main.css` |
| Bootstrap | `src/styles/vendor/bootstrap.css` - don't edit this, override it in `main.css` |

Anything in `dist/` is generated by the build. Never edit it.

### Adding a game

1. Copy a file in `src/content/games/` and rename it. The filename becomes the URL, so
   `hotel-77.md` is `/games/hotel-77/`.
2. Give it an `order` higher than the others so it shows up first.
3. Put the image in `public/img/portfolio/`.

That one file produces the grid card, the popup and the standalone page.

### How the popups work

Clicking a game opens the popup over the homepage and changes the URL to
`/games/<slug>/`. Back closes it. The same URL is also a real page, so shared links,
opening in a new tab and search engines all get proper HTML. Code is in
`src/components/ModalRouting.astro`.

## Deployment

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds the site and
publishes it. This requires **Settings → Pages → Source = "GitHub Actions"**.
